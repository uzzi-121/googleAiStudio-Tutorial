# 🎙️ 유튜브 오디오 다운로드 & Gemini STT 트랜스크립터 웹서비스

유튜브 영상 URL을 입력하면 영상의 오디오 스트림을 고속 다운로드하고, Google의 최신 `gemini-3.5-transcribe` 모델을 통해 타임스탬프와 전체 자막(트랜스크립트)을 자동 추출해 주는 Streamlit 기반 웹서비스입니다.

---

## 🌟 주요 기능

1. **오디오 고속 추출 (`yt-dlp`)**:
   - 영상 전체를 받지 않고 최적의 오디오 스트림(m4a/mp3)만 분리 다운로드하여 속도가 매우 빠릅니다.
2. **Gemini 3.5 Transcribe 연동**:
   - Google AI Studio의 공식 오디오 특화 모델을 활용한 고정확도 음성 인식(STT).
   - 단어 타임스탬프를 문장 종결 부호(`.`, `?`, `!`) 기준으로 묶어 자연스러운 문장별 타임스탬프 생성.
3. **풍부한 웹 UI (Streamlit)**:
   - 유튜브 썸네일, 제목, 채널 정보 표시
   - 웹 브라우저 내 오디오 직접 재생 플레이어
   - 전체 텍스트 뷰 및 복사 기능
   - 문장별 타임스탬프 리스트 뷰
   - 영상 편집(프리미어, 컷편집)에 바로 쓸 수 있는 **`.srt` 자막 파일 및 `.txt` 파일 다운로드**

---

## 🚀 실행 방법

### 1. 패키지 설치
터미널에서 가상환경을 활성화한 후 다음 명령어를 실행합니다:
```bash
pip install -r requirements.txt
```

### 2. 웹서비스 실행
```bash
streamlit run app.py
```

명령어를 실행하면 자동으로 기본 웹 브라우저(`http://localhost:8501`)가 열립니다.

---

## 💡 사용 방법
1. 좌측 사이드바에 **Gemini API Key**를 입력합니다 (환경 변수에 `GEMINI_API_KEY`가 등록되어 있다면 자동으로 채워집니다).
2. 원하는 유튜브 영상의 주소(URL)를 복사하여 입력창에 붙여넣습니다.
3. **[🚀 오디오 추출 및 트랜스크립트 생성]** 버튼을 클릭합니다.
4. 분석이 끝나면 웹에서 오디오를 들어보거나, 문장별 타임스탬프 확인 및 `.srt` 자막 파일을 다운로드할 수 있습니다.
