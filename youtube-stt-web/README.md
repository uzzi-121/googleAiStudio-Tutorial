# 🎙️ YouTube AI Search: 고정밀 STT & AI 영상 분석 웹서비스

유튜브 영상 URL을 입력하면 영상의 고음질 오디오를 고속 다운로드하고, Google의 최신 `gemini-3.5-transcribe` 및 `gemini-3.6-flash` 모델을 통해 타임스탬프 자막 추출, 영상 핵심 요약, 키워드 태깅, 끊김 없는 타임스탬프 연동, 그리고 YouTube 공식 AI 스타일 질의응답 챗봇을 제공하는 모던 풀스택 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **독립형 모던 HTML5/CSS3/JavaScript 웹 프론트엔드**:
   - Streamlit의 한계(페이지 전체 새로고침, iframe 제약)를 극복한 순수 DOM 기반의 부드러운 인터랙션.
   - 16:9 반응형 YouTube 플레이어 및 커스텀 컨트롤 바 (재생/일시정지, 볼륨 슬라이더, 음소거 토글, CC 자막 ON/OFF, 실시간 타임 카운터).
   - **끊김 없는 타임스탬프 스킵**: 시간 버튼(`▶ 00:00`)이나 문장 클릭 시 영상 재생이 멈추지 않고 해당 초로 즉시 이동.
2. **YouTube AI 공식 스타일 '이 동영상에 대해 물어보세요' Q&A**:
   - 영상 내용을 분석하여 시청자가 가장 궁금해할 맞춤형 예상 질문지 5개(알약 버튼) 자동 추천.
   - 추천 질문 알약 버튼 클릭 시 텍스트가 잘리지 않고 온전하게 노출되며, 클릭 즉시 질문이 전송되어 AI 챗봇이 타임스탬프(`[MM:SS]`)와 함께 상세 답변 제공.
3. **고속 오디오 추출 & Gemini 파이프라인**:
   - `yt-dlp` 기반 고속 오디오 분리 다운로드.
   - `gemini-3.5-transcribe`: 화자 분리(Diarization) 및 단어별 정밀 타임스탬프 STT.
   - `gemini-3.6-flash`: 스크립트 기반 핵심 요약(3~5개 불릿) 및 주요 키워드 추출.
4. **자막 내보내기 & 전체 스크립트**:
   - 영상 편집(프리미어, 컷편집)에 바로 쓸 수 있는 `.srt` 자막 및 `.txt` 파일 즉시 다운로드.
   - 전체 스크립트 원클릭 클립보드 복사.

## 🚀 실행 방법

### 1. 패키지 설치
터미널에서 가상환경을 활성화한 후 다음 명령어를 실행합니다:
```bash
pip install -r requirements.txt
```

### 2. 웹서비스 실행 (추천: HTML / FastAPI 웹앱)
```bash
python server.py
```
*(또는 윈도우 탐색기에서 `run.bat` 파일을 더블 클릭하여 원클릭 실행 가능)*

명령어를 실행하면 자동으로 기본 웹 브라우저(`http://127.0.0.1:8000`)가 열립니다.

> **참고**: 기존 Streamlit 버전으로 구동하려면 `streamlit run app.py`를 실행할 수 있습니다.

---

## 💡 사용 방법
1. 환경 변수에 `GEMINI_API_KEY`가 등록되어 있는지 확인합니다.
2. 상단 검색창에 분석하고 싶은 유튜브 영상 주소(URL)를 입력하고 **[🔍 분석]** 버튼을 누릅니다.
3. 분석이 완료되면 좌측에서 영상을 시청하며, 우측 3대 탭(📊 대시보드, ⏱️ 타임스탬프, 💬 AI 질의응답)을 자유롭게 이용할 수 있습니다.
